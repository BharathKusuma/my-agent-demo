## Contribution Guidelines

We welcome contributions! Please follow these steps:
1. **Fork the repository**.
2. **Create a feature branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** and ensure they adhere to the coding style.
4. **Write tests** for new functionality.
5. **Run the test suite**:
   ```bash
   pytest
   ```
6. **Commit your changes** with clear messages.
7. **Push to your fork** and open a Pull Request.

### Code Style
- Follow PEP8 (or relevant style guide).
- Use descriptive variable and function names.
- Include docstrings for public modules, classes, and functions.

### Reporting Issues
If you encounter a bug or have a feature request, please open an issue with a clear description and steps to reproduce.
